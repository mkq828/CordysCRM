# 企业知识库：序号排序 + 在线查看文件

## 背景
用户提出两个增强：① 列表加「序号」列，可直接填数字，按升序排序；② 在线查看文档（pdf/docx/md/txt）。

## 关键决策（已拍板）
- **序号**：`ai_knowledge_doc` 加 `sort_no INT NULL`，新上传默认 NULL（排最后）；填了序号的按升序排前面。允许重复，重复按创建时间倒序兜底。
- **在线查看**：上传时把原文件存为正式附件（`sys_attachment`，`resourceId = docId`），`ai_knowledge_doc` 加 `attachment_id` 关联。
- **边界**：历史已上传文档没有原文件，无法在线查看，需重新上传。
- **渲染**：PDF 走浏览器原生（前端 blob + iframe）；docx 用 mammoth.js 前端转 HTML；md/txt 直接展示文本。
- 附件复用现有 `AttachmentService.uploadTemp` + `processTemp`，预览复用 `/attachment/download/{id}`（前端带 token 走 blob fetch）。
