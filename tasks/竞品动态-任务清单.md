# 竞品动态 · 任务清单

> 联网地基能力场景 5：竞品最新动态订阅监控与提醒。给销售/老板一个「盯住竞品在干什么」的常驻入口。

## 范围与定位

- **做什么**：用户在 AI 创作中心维护关注的竞品（竞品名 + 可选关键词），系统每天定时（8:20）联网搜索该竞品的最新动态（新闻/融资/新品等），按 URL 去重落库，新动态站内信推给订阅人；也可手动「立即搜索」。
- **与既有「竞品情报」的关系**：既有「竞品情报」（`menu.aiLeadCrawl` / `CompetitorInsightService`）是**纯 LLM 洞察简报**（输入竞品名 → 生成洞察，无联网、无订阅推送），二者**并存不冲突**。本功能是**联网订阅监控**，独立新页「竞品动态」。
- **门控与额度**：复用 `lead_crawl`（与潜客挖掘、标讯订阅同一版本/额度口径），搜索按次折算 token 记账。

## 决策记录（我的决定 + 理由）

- **独立新页，不动既有竞品情报**：既有竞品情报是会话式纯 LLM 简报，本功能是订阅式联网监控，两种交互范式差异大，硬塞进同一页会互相干扰；沿用标讯订阅的成熟双栏模式最稳。
- **订阅字段只保留「竞品名(必填) + 关键词(可选)」**：比标讯（行业/地域/关键词）更贴合「盯某个竞品」的语义，字段越少越不会填错。
- **定时错峰 8:20**：避开标讯订阅的 8:00，两个联网任务不同时打 DeepSeek，降低限流与并发压力。

## 数据模型（迁移 1.59.0.3）

- `ai_competitor_subscription`：id / organization_id / user_id / competitor(必填) / keyword / enabled / 审计四列。
- `ai_competitor_result`：id / organization_id / subscription_id / title / url / snippet / content / 审计四列，`UNIQUE(subscription_id, url)` 去重。
- 本次两表**一开始就带 update_time/update_user**（吸取标讯 `1.59.0_2` 补列的教训）。
