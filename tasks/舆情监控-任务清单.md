# 舆情监控 · 任务清单

> 联网地基能力场景 6：品牌 / 重点客户 / 供应商负面舆情监测，提前预警（爆雷、涉诉、欠薪等）。

## 范围与定位

- **做什么**：用户在 AI 创作中心维护关注的监控对象（品牌/客户/供应商名 + 可选关键词），系统每天定时（8:40）联网搜索该对象的负面/风险信号（涉诉、欠薪、爆雷、舆情等），按 URL 去重落库，新风险站内信推给订阅人；也可手动「立即搜索」。
- **与标讯订阅/竞品动态的关系**：三者同为「订阅式联网搜索 + 定时 + 去重 + 站内信推送」的同一范式，只是搜索语义不同（招标 / 竞品动态 / 负面舆情）。本功能独立新页，复用同一 `lead_crawl` 门控/额度。

## 决策记录（我的决定 + 理由）

- **订阅字段「监控对象(必填) + 关键词(可选)」，对象自由填写**：先做 MVP，与标讯/竞品动态保持一致的自由文本输入；「关联到 CRM 已有客户/供应商」是更重的集成（选对象、绑实体、回填），价值大但属二期，本期不做。
- **搜索词偏负面/风险**：舆情监控的核心是「提前预警」，搜索词固定带 `负面 舆情 涉诉 风险`，结果标题即风险线索。
- **定时错峰 8:40**：接在标讯 8:00、竞品动态 8:20 之后，三个联网任务不同时打 DeepSeek。

## 数据模型（迁移 1.59.0.4）

- `ai_sentiment_subscription`：id / organization_id / user_id / target(监控对象,必填) / keyword / enabled / 审计四列。
- `ai_sentiment_result`：id / organization_id / subscription_id / title / url / snippet / content / 审计四列，`UNIQUE(subscription_id, url)` 去重。
- 两表一开始就带 update_time/update_user。
