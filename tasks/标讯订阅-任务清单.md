# 标讯订阅（联网地基·场景 4）· 任务清单

> 目标：联网找招投标信息，支持订阅 + 定时搜索 + 站内信推送。
> 定位：AI 创作中心下新功能「标讯订阅」，与潜客挖掘同级；不动现有「标讯(大单网 iframe)」菜单。

## 决定（已拍板）

- featureCode 复用 `lead_crawl`（同属联网找客户/商机类），额度复用搜索按次折算记账。
- 推送走站内信（企微不可用），复用 `CommonNoticeSendService`。
- 定时搜索：每天 8:00（`@QuartzScheduled`），另留手动「立即搜索」便于验收。

## 数据模型（Flyway 迁移，2 张表）

- `ai_tender_subscription`：id / org_id / user_id / industry / region / keyword / enabled / create_time / update_time。
- `ai_tender_result`：id / org_id / subscription_id / title / url(唯一) / snippet / content / create_time。
