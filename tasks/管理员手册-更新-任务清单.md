## 已核实的事实（来源：代码 + git log + 浏览器实测）

- 「平台运营」菜单现含 6 个子页：版本套餐 / 系统日志 / 问题反馈 / **安全事件** / **定时任务执行记录** / **系统错误记录**（后 3 个手册缺）。
- 安全事件页：事件类型 SQL注入/XSS/路径穿越/扫描器/高频报错，支持导出 CSV、查看详情（IP/UA/URI/转发链/归属地/traceId/租户ID 等）。
- 系统错误记录页：按报错类/traceId/错误关键词筛，看错误信息 + 异常堆栈。
- 定时任务执行记录页：任务名/状态(运行中/成功/失败)/开始结束时间/耗时/失败信息。
- 企微通知：群机器人 Webhook 推 markdown 到管理员群（企业注册申请时，含公司名/联系人/电话/申请时间/审批链接），个人注册不推；群机器人模式无需企业ID/应用ID/密钥/可信IP；企微 OAuth 扫码登录已关闭，登录页只留账号密码/短信验证码。
- AI 模型：agent_model 统一挂默认组织 100001 下由 admin 配，**所有租户共享**；租户 orgId 仅用于额度/权限判定，不再影响模型选择。
