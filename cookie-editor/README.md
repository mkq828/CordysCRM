# 私信获客 Cookie 助手（Chrome / Edge 插件）

给非技术用户用的「抖音登录 Cookie」一键导出工具，替代「F12 开发者工具」那一套难操作的方式。

安装一次后，使用流程就三步：**登录抖音 → 点插件 → 复制**，然后把内容粘贴到 CRM 的「私信获客画像 → 绑定账号」即可。

## 为什么用插件，而不是教用户按 F12

抖音的关键登录项里，`sessionid_ss` 是 httpOnly Cookie，普通网页脚本（书签小工具）读不到它；只有浏览器插件的 `cookies` 权限能拿到。所以做成插件是最省事、也最可靠的方式。

## 安装步骤（一次性，约 1 分钟）

### Chrome

1. 打开 `chrome://extensions/`
2. 右上角打开「**开发者模式**」
3. 点左上角「**加载已解压的扩展程序**」
4. 选择本目录 `cookie-editor/`（就是包含 `manifest.json` 的那个文件夹）
5. 安装完成，工具栏出现插件图标（建议点图钉把它固定住）

### Edge

1. 打开 `edge://extensions/`
2. 左侧打开「**开发人员模式**」
3. 点「**加载解压缩的扩展**」
4. 选择本目录 `cookie-editor/`
5. 完成

## 使用步骤

1. 在浏览器打开并**登录** https://www.douyin.com/ （务必是登录状态）
2. 点工具栏的「私信获客 Cookie 助手」图标
3. 弹出窗口会显示登录态是否完整：
   - `✓ sessionid_ss` / `✓ uid_tt` 都在 → 绿色「已登录」→ 点「**复制 Cookie**」
   - 有 `✗` → 说明没登录或登录失效，先回抖音重新登录
4. 回到 CRM：**工作台 → 私信获客画像 → 绑定账号**，把复制的内容粘贴进输入框，点绑定

## 输出格式说明

插件复制出来的是形如 `sessionid_ss=xxx; uid_tt=yyy; sid_tt=zzz; ...` 的一串文本，这是抖音请求头 Cookie 的标准格式，CRM 后端已兼容（也兼容 Cookie-Editor / EditThisCookie 导出的 JSON 格式）。

## 安全说明

- 插件**只**在浏览器本地读取 `douyin.com` 的 Cookie，复制到你的剪贴板，不上传任何服务器。
- Cookie 等同你的抖音登录凭证，请只粘贴进你自己信任的 CRM；不要发到聊天群或截图外传。
- 若担心账号安全，绑定完成后可在抖音 App/网页退出登录，使该 Cookie 失效。

## 扩展其它平台

当前只支持抖音（`douyin.com`）。等「私信获客画像」接入快手 / 小红书后，在 `manifest.json` 的 `host_permissions` 增加对应域名、在 `popup.js` 增加对应必填项即可复用。
