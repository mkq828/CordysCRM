==============================
验收步骤（按计划 6 条）
① 菜单与权限
admin 登录 → 左侧出现「城市经理」一级菜单，含「经理账号」「业绩看板」两个子项。

② 新增城市经理
「经理账号」→「新增经理」→ 填姓名 + 手机号（密码留空）→ 列表出现该经理、状态「在职」。

③ city_manager 登录与权限隔离
退出 admin，用刚才的手机号 + 123456 登录 → 左侧只应有「业绩看板」，不应出现「经理账号」。

④ 业绩看板
「业绩看板」页：周/月/年维度切换 + 汇总表 + 趋势图。

admin：有「经理下拉」可看全部/指定经理
city_manager 本人：没有经理下拉，强制只看自己
⑤ 离职禁用 + 二次分配
admin 回「经理账号」→ 对某经理点「离职禁用」→ 状态变「离职」（该经理在线会被踢下线）；点「二次分配」→ 选原经理 / 目标经理 / 待转移租户 → 确认。

⑥ 单点登录（踢下线）
同一经理账号：A 窗口登录 → B 窗口（或隐身窗口）再登录 → 回 A 窗口点任意操作 → 弹「该账号已在其他设备登录」并跳回登录页。
