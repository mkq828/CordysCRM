## 二、地基（P0，先做）

### G1 — 模型可配置适配层（分场景路由）
- **做什么**：抽象 `LlmProvider` 接口，实现千问（DashScope）/ DeepSeek / 豆包（火山引擎）/ MaxKB；一张「场景路由」配置把 `feature_code → model_code`，**不同 AI 功能用不同模型**（军师→千问、获客文案→豆包、生成类→专门生成模型）。
- **统一出口**：每次调用把 `usage`（input/output token 分开）吐给计量层，供 G2 记账。
- **依赖**：无（替换现有写死的 `AgentBaseService` 里的 `config.getMkAddress()`）。
- **验收**：配置里切换模型后，AI 对话无需改代码即走新模型；`usage` 字段能取到 input/output token。

### G2 — AI 额度框架（计量/配额/加购/熔断/双看板）
- **做什么**：PRD §9 全部——计量（按 token 折「次数」）、月配额次月 1 日重置、加购包、软超(100–110% 限速提示)/硬超(>110% 停用)、单租户限流 + 单日成本熔断、租户端「次数」看板 + admin「成本」看板。
- **依赖**：G1（拿 usage）、G3（按功能区分计量）。
- **验收**：某租户额度用尽后 AI 功能按规则停用/提示；admin 能按租户/天看真实 token 成本。

### G3 — AI 功能挂 feature_code（版本/全局开关）
- **做什么**：把 12 个 AI 功能各注册一个 `feature_code`，挂到 `sys_feature` + `sys_edition_feature`，支持「版本归属」+「全局开关」两个维度（表已建，只接线）。
- **依赖**：无。
- **验收**：admin 勾选某版本含某 AI 功能后，该版本租户可见该功能入口；全局禁用后所有租户入口隐藏。

## 三、第一期 AI 功能（签单 + 获客，低 token 成本，打包订阅价）

### 功能 1 — AI 销售会话军师（多通道：粘贴 / 截图 / 企微存档）
- **做什么**：销售把与客户的聊天通过「粘贴文本 / 截图 OCR / 企微会话存档（后续）」交给 AI → 输出 意向评分、成交信号、异议点、情绪/满意度、竞品提及、流失风险 → 候选话术（从话术库检索+改写）→ **一键转跟进**。
- **复用**：现有 Agent 平台（对话/流式/确认）+ G1 模型层；打分可借 kev（决策引擎，本地小模型）。
- **来源**：PaddleOCR（截图 OCR）+ FunASR（语音转写，可选）。
- **说明**：企微「会话存档 API 自动获取」版等上线后再接（受企业可信 IP 60020 限制），上传页展示「开通自动获取」引导卡。
- **依赖**：G1、G2、G3、功能 2（话术库，可选）。
- **验收**：粘贴/截图一段对话，30s 内出结构化分析 + 话术，可一键落跟进记录。

### 功能 2 — 销售话术库（RAG 检索）
- **做什么**：租户沉淀自己的销售话术/常见异议应答，AI 按客户情况检索并改写推荐话术；也是功能 1「候选话术」的数据源。
- **来源**：ragflow / MaxKB（RAG 检索底座）。
- **依赖**：G1、G2、G3。
- **验收**：输入客户场景，返回 3 条贴合的话术 + 出处。

### 功能 3 — AI 获客内容生成（选题/文案/图文）
- **做什么**：输入行业/产品，AI 生成抖音/小红书/朋友圈的选题、爆款文案、配图文案。
- **复用**：`marketingskills` 等已下载 skill 的 prompt 模板；ZJU-REAL/Easel（自媒体选题/创作/发布一条龙）；应用编排参考 dify / lobe-chat。
- **依赖**：G1、G2、G3。
- **验收**：一键生成 5 条选题 + 对应文案，可复制/导出。

## 四、第二期 AI 功能（生成类 / 企业版，高成本走增值包）

### 功能 4 — 企业知识库（RAG + 文档解析）
- **做什么**：租户上传产品文档/合同/手册，AI 解析建库，问答/检索。是后续多个功能的 RAG 基座。
- **来源**：ragflow（首选，Apache-2.0）/ MaxKB（GPL）/ 腾讯 WeKnora（GPL）；文档解析 **anydoc（扫描件 OCR 重解析）+ markitdown（电子版 Office/PDF 转 Markdown，微软 MIT，轻快）** 互补。
- **依赖**：G1、G2、G3。
- **验收**：上传文档后可自然语言问答，答案带出处。

### 功能 5 — AI 方案/PPT 生成
- **做什么**：输入客户背景，AI 生成解决方案大纲 + PPT 初稿。
- **来源**：dashi-ppt、anydoc；Office 运行时参考 univer。
- **依赖**：G1、G2、G3、功能 4（知识库，可选）。
- **验收**：输入需求，产出可下载的方案文档/PPT。

### 功能 6 — AI 员工（144 员工，编排层）
- **做什么**：把 144 个 AI 员工 skill 落成租户可配置的 Agent（岗位分工、自动跑任务），在现有 Agent 平台上发布。
- **来源**：agency Agents、metagpt、144 个 AI 员工 repo；编排运行时参考 google/ax、n8n（工作流）；私有助手参考 TencentCloud/Octop；企业数字员工平台参考 LinkWork（Apache-2.0，配额/审计/K8s）与 StaffDeck（⚠️AGPL，仅抄思路）。
- **依赖**：G1、G2、G3、功能 4（知识库赋能）。
- **验收**：租户可创建/配置一个「岗位 Agent」，跑通一个端到端任务。

### 功能 7 — 短视频/数字人/爆款复刻
- **做什么**：上传素材 → 生成口播视频/数字人视频/爆款复刻，用户手动下载发布（不做自动发布，防封号）。
- **来源**：MoneyPrinterTurbo（纯 AI 文本成片，首选）/ ZJU-REAL/Easel（图文转视频 slideshow-video + AI 视频生成 ai-video-gen）/ LongCat、avatar-forge、hypit、OpenMontage、FFmpeg。
- **依赖**：G1、G2、G3；走增值包加购。
- **验收**：上传素材产出可下载视频 + 各平台配套文案。

### 功能 8 — 私信获客画像（抖音/快手/小红书，Beta）
- **做什么**：租户扫码登录自己账号 → 读私信 → AI 画像（性别/年龄/品类/话术）→ 进 CRM 客户池。
- **来源**：16.test + scrapling（Python 微服务）。
- **硬约束**：只拿租户自己账号私信；封号风险租户自担 + 小号先试 + 限频 + 免责声明。
- **依赖**：G1、G2、G3、独立 Python 微服务（Playwright，每租户几百 MB 内存）。
- **验收**：Beta 环境跑通「扫码→读私信→画像→进客户池」。

### 功能 9 — AI 语音外呼
- **做什么**：AI 外呼/客服，语音合成 + 对话，结果落 CRM 跟进。
- **来源**：SpeechToSpeech；生产级用 FunASR（STT）+ CosyVoice（TTS）自建组件。
- **依赖**：G1、G2、G3、功能 11（声音，可选）；走增值包。
- **验收**：配置话术后可自动外呼，通话记录/意向回落 CRM。

### 功能 10 — 线索爬取 + 竞品/行业洞察
- **做什么**：按行业/关键词抓公开线索 + 竞品动态/行业趋势，进线索池。
- **来源**：scrapling、browser-use / jev-ultrafast（无脚本浏览器）、MiroFish、WeMM。
- **依赖**：G1、G2、G3；合规边界需评估。
- **验收**：输入关键词产出线索清单（含来源），可导入线索池。

### 功能 11 — 声音克隆（能力组件）
- **做什么**：克隆指定音色，供功能 7（数字人）、功能 9（外呼）复用。
- **来源**：VoxCPM、WeClone；CosyVoice（自带音色克隆，可选）。
- **依赖**：G1、G2、G3；走增值包；需合规授权声明。
- **验收**：上传样本产出可用的克隆音色。

### 功能 12 — AI 问数 BI（大白话查数，Text-to-SQL）
- **做什么**：销售/财务看板「大白话问数」——自然语言 → SQL 直连 MySQL 出图表，省去手写报表。
- **来源**：vanna（MIT，Text-to-SQL 直连 MySQL）。
- **依赖**：G1、G2、G3；财务/应收模块已建，正好接回款/合同数据。
- **验收**：输入「上月各客户回款金额 Top10」，返回结果 + 图表 + 生成的 SQL。

## 五、执行顺序（推荐）

1. **P0 地基（G1→G2→G3）**：先解耦模型 + 建额度 + 功能开关，这一步做完，后面所有 AI 功能才能「上线即收费、可计量、可关停」。
2. **一期（功能 1→2→3）**：功能 1（会话军师）复用现有 Agent 平台最快见效，功能 2（话术库）给它供话术，功能 3（获客内容）紧随；都是文本类低 token 成本，直接打包进订阅价。
3. **二期（功能 4→…→12）**：先 4（知识库 RAG 基座，低本高复用），再按「中成本→高成本」做方案/PPT(5)、AI 员工(6)、线索(10)、短视频(7)、私信(8)、外呼(9)、声音(11)，高成本生成类走增值包；12（问数 BI）成本低、接现成财务数据，可提前。
4. 每个功能开工前，单独展开一份该功能的详细 PRD + 数据模型 + 接口清单，再动手。

## 六、来源仓库已下载说明（2026-09-28 更新）

2026-09-28 补下 26 个参考仓库 + MoneyPrinterTurbo 后，本清单各功能的「来源」已按**实际已下载仓库**更新：ragflow/MaxKB（RAG）、PaddleOCR（OCR）、FunASR/CosyVoice（语音）、vanna（问数）、kev（打分）、ax/n8n/Octop（AI 员工编排）、univer（Office 渲染/编辑运行时，非 AI 生成）、jev-ultrafast（无脚本浏览器）、MoneyPrinterTurbo（短视频成片）、ZJU-REAL/Easel（自媒体一条龙）。

2026-09-29 网络到期前补下三处来源：qdrant（向量库，功能 2/4 的 RAG 向量存储底座）、langgraph（Agent 编排运行时，功能 6）、markitdown（微软 MIT 文档转 Markdown，功能 4 电子版文档解析）。

**ZJU-REAL/Easel 单独说明**（Apache-2.0，Python + OpenClaw，113 个 skill，759M）：它是「获客 + 传播」线的**整合参考底座**，五段式覆盖 发现（热点/竞品/受众画像）→ 策划（选题/内容矩阵/日历）→ 创作（文案/图文/视频/音乐/配音）→ 发布（小红书/抖音/B站/知乎/快手/微信）→ 复盘（数据/评分/归因）。对应本清单 功能3（获客内容）、功能7（短视频）、功能8（私信获客）三处，可复用其 skill prompt + `skills/shared/scripts/*.py` 脚本思路。两个边界：① 它是独立 Python 系统（含 Web UI），只能「抄思路 + prompt + 脚本」，不能整搬进 Java/Vue CRM；② 它的「一键自动发布」有封号风险，与本清单「内容生成 + 手动下载发布」的防封号口径一致——只参考创作侧，不接自动发布侧。

**未纳入本清单的下载项**（非 AI 功能，留作产品/安全参考）：四类借鉴系统（skyeye/metasfresh/t3rik-erp/wimoor/OmniTradeERP/mall/litemall/newbee-mall/lobe-chat/dify/open-webui）是 ERP/电商/AI 超市的产品与架构参考；security-audit-skill（供应链安全）、openbao（密钥托管）属安全基建，均不与 12 个 AI 功能一一对应。

## 七、去重与模块关系（2026-09-28）

- **已合并**：原「功能 1 客户军师」与「功能 4 企微会话分析」分析维度几乎 100% 重叠（意向/信号/异议/竞品/流失风险），仅是输入通道不同 → 合并为现「功能 1 销售会话军师」（粘贴 / 截图 OCR / 企微存档多通道），13 个功能精简为 12 个，避免重复开发。
- **底座复用（非重复）**：功能 2（话术库）与功能 4（知识库）共用同一个 RAG 底座（ragflow），只是知识域不同（话术域 vs 企业文档域）。
- **组件复用（非重复）**：功能 11（声音克隆）是能力组件，被功能 7（数字人）、功能 9（外呼）复用；功能 2（话术库）被功能 1（候选话术）复用；功能 4（知识库）被功能 5/6 复用。
- **编排层（非并列功能）**：功能 6（AI 员工）是把 1~12 的原子能力包成「岗位 Agent」的编排/平台层，不是与它们平级的单个功能。
- **边界提醒**：功能 3（文本/图文内容）与功能 7（视频）共享「选题/策划」环节（ZJU-REAL/Easel 的 discovery/planning 段），但生成管线与成本差异大（文本低 token、视频高成本走增值包），分开保留；功能 8（私信画像）与功能 10（线索爬取）同属「获客线索采集」但来源/实现不同，分开保留。
