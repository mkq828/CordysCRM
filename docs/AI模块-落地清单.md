## 一、总览

**总共：3 项地基 + 12 个 AI 功能 + 2 项新增能力（客户画像 / 数据大屏）。**

开发优先级 = 序号从前往后做。地基（G1→G3）是所有 AI 功能收费/运行的前提，必须先做；功能（1→12）按「成本低 → 价值高 → 依赖少」排序。

## 二、地基（P0，先做）

### G1 — 模型可配置适配层（分场景路由）
- **做什么**：抽象 `LlmProvider` 接口，实现千问（DashScope）/ DeepSeek / 豆包（火山引擎）/ MaxKB；一张「场景路由」配置把 `feature_code → model_code`，**不同 AI 功能用不同模型**（军师→千问、获客文案→豆包、生成类→专门生成模型）。
- **统一出口**：每次调用把 `usage`（input/output token 分开）吐给计量层，供 G2 记账。
- **依赖**：无（替换现有写死的 `AgentBaseService` 里的 `config.getMkAddress()`）。
- **验收**：配置里切换模型后，AI 对话无需改代码即走新模型；`usage` 字段能取到 input/output token。

### G2 — AI 额度框架（计量/配额/加购/熔断/双看板）
- **做什么**：PRD §9 全部——计量（按 token 折「次数」）、月配额次月 1 日重置、加购包、软超(100–110% 限速提示)/硬超(>110% 停用)、单租户限流 + 单日成本熔断、租户端「次数」看板 + admin「成本」看板。
- **依赖**：G1（拿 usage）、G3（按功能区分计量）。
- **验收**：某租户额度用尽后 AI 功能按规则停用/提示；admin 能按租户/天看真实 token 成本。

### G3 — AI 功能挂 feature_code（版本/全局开关）
- **做什么**：把各 AI 功能注册 `feature_code`，挂到 `sys_feature` + `sys_edition_feature`，支持「版本归属」+「全局开关」两个维度（表已建，只接线）。查看型功能（画像/大屏）只挂这一层，不走额度计量。
- **依赖**：无。
- **验收**：admin 勾选某版本含某 AI 功能后，该版本租户可见该功能入口；全局禁用后所有租户入口隐藏。

## 三、第一期 AI 功能（签单 + 获客，低 token 成本，打包订阅价）

### 功能 1 — AI 销售会话军师（多通道：粘贴 / 截图 / 企微存档）
- **做什么**：销售把与客户的聊天通过「粘贴文本 / 截图 / 企微会话存档（后续）」交给 AI → 输出 意向评分、成交信号、异议点、情绪/满意度、竞品提及、流失风险 → 候选话术（从话术库检索+改写）→ **一键转跟进**。
- **复用**：现有 Agent 平台（对话/流式/确认）+ G1 模型层；截图走豆包多模态直接读图（不 OCR）。
- **来源**：豆包 vision 多模态（读图）；企微「会话存档 API」等上线后再接（受企业可信 IP 60020 限制）。
- **依赖**：G1、G2、G3、功能 2（话术库，可选）。
- **验收**：粘贴/截图一段对话，30s 内出结构化分析 + 话术，可一键落跟进记录。
- **进度**：`[x]` 已上线（`/agent/advisor/analyze`，featureCode=`ai_advisor`）。

### 功能 2 — 销售话术库（RAG 检索）
- **做什么**：租户沉淀自己的销售话术/常见异议应答，AI 按客户情况检索并改写推荐话术；也是功能 1「候选话术」的数据源。
- **来源**：ragflow / MaxKB（RAG 检索底座），qdrant（向量库）。
- **依赖**：G1、G2、G3。
- **验收**：输入客户场景，返回 3 条贴合的话术 + 出处。

### 功能 3 — AI 获客内容生成（选题/文案/图文）
- **做什么**：输入行业/产品，AI 生成抖音/小红书/朋友圈的选题、爆款文案、配图文案。
- **复用**：`marketingskills` 等已下载 skill 的 prompt 模板；ZJU-REAL/Easel（自媒体选题/创作/发布一条龙）；应用编排参考 dify / lobe-chat。
- **依赖**：G1、G2、G3。
- **验收**：一键生成 5 条选题 + 对应文案，可复制/导出。

## 四、第二期 AI 功能（生成类 / 企业版，高成本走增值包）

### 功能 4 — 企业知识库（RAG + 文档解析）
- **做什么**：租户上传产品文档/合同/手册，AI 解析建库，问答/检索。是后续多个功能的 RAG 基座。
- **来源**：ragflow（首选，Apache-2.0）/ MaxKB（GPL）/ 腾讯 WeKnora（GPL）；文档解析 **anydoc（扫描件 OCR 重解析）+ markitdown（电子版 Office/PDF 转 Markdown，微软 MIT，轻快）** 互补。
- **依赖**：G1、G2、G3。
- **验收**：上传文档后可自然语言问答，答案带出处。

### 功能 5 — AI 方案/PPT 生成
- **做什么**：输入客户背景，AI 生成解决方案大纲 + PPT 初稿。
- **来源**：dashi-ppt、anydoc；Office 运行时参考 univer。
- **依赖**：G1、G2、G3、功能 4（知识库，可选）。
- **验收**：输入需求，产出可下载的方案文档/PPT。

### 功能 6 — AI 员工（144 员工，编排层）
- **做什么**：把 144 个 AI 员工 skill 落成租户可配置的 Agent（岗位分工、自动跑任务），在现有 Agent 平台上发布。
- **来源**：agency Agents、metagpt、144 个 AI 员工 repo；编排运行时参考 google/ax、n8n（工作流）；私有助手参考 TencentCloud/Octop；企业数字员工平台参考 LinkWork（Apache-2.0，配额/审计/K8s）与 StaffDeck（⚠️AGPL，仅抄思路）。
- **依赖**：G1、G2、G3、功能 4（知识库赋能）。
- **验收**：租户可创建/配置一个「岗位 Agent」，跑通一个端到端任务。

### 功能 7 — 短视频/数字人/爆款复刻
- **做什么**：上传素材 → 生成口播视频/数字人视频/爆款复刻，用户手动下载发布（不做自动发布，防封号）。
- **来源**：MoneyPrinterTurbo（纯 AI 文本成片，首选）/ ZJU-REAL/Easel（图文转视频 slideshow-video + AI 视频生成 ai-video-gen）/ LongCat、avatar-forge、hypit、OpenMontage、FFmpeg。
- **依赖**：G1、G2、G3；走增值包加购。
- **验收**：上传素材产出可下载视频 + 各平台配套文案。

### 功能 8 — 私信获客画像（抖音/快手/小红书，Beta）
- **做什么**：租户扫码登录自己账号 → 读私信 → AI 画像（性别/年龄/品类/话术）→ 进 CRM 客户池。
- **来源**：16.test + scrapling（Python 微服务）。
- **硬约束**：只拿租户自己账号私信；封号风险租户自担 + 小号先试 + 限频 + 免责声明。
- **依赖**：G1、G2、G3、独立 Python 微服务（Playwright，每租户几百 MB 内存）。
- **验收**：Beta 环境跑通「扫码→读私信→画像→进客户池」。

### 功能 9 — 智能通话复盘（第一版） + AI 机器人外呼（远期）

**第一版：智能通话复盘（配置化对接外呼系统，不自建呼叫）**
- **做什么**：销售用**已经在用的外呼系统**打电话（百应/探迹/容联/阿里云外呼，或长尾小厂），通话数据（记录+录音）回流 CRM → 语音转文字 → AI 分析（意向/异议/话术/复盘）→ 落跟进。本质是**会话军师的「语音通道」**。第一版最轻：不碰呼叫、不碰线路、不碰实时语音。
- **三层接入架构**：
  1. **通用回调接入（兜底长尾，零开发）**：CRM 提供统一回调地址 + 密钥 + 「字段映射」配置页；任何外呼供应商把通话结果（通话时间/主叫/被叫/时长/录音 URL/转写文本）POST 到回调地址，租户在配置页把供应商字段映射到 CRM 标准字段即接入。**覆盖所有中小便宜厂商，不用一家家开发适配器**。
  2. **官方适配器（4 家预置，开箱即用）**：容联云、百应、探迹、阿里云外呼——主动拉取 + 预置字段映射，租户只填 API Key/授权。**分阶段做**（先 1 家跑通样板，再复制 3 家）。
  3. **（远期）自建点击呼叫**：闭环呼叫，另议。
- **语音转文字**：云厂商录音转写 API（按量计费 2.5 元/时标准 / 1.56 极速 / 0.6 闲时，转嫁租户）。
- **AI 分析**：复用会话军师 LLM 逻辑。
- **关键前提**：依赖外呼系统的 API/回调开放程度；「配置化」省实施对接人工、不省适配开发——所以大牌走官方适配器、长尾走通用回调。
- **不做**：不做机器人外呼、不碰实时语音引擎、不自建 GPU、不自建点击呼叫（第一版），零风控、零 GPU 成本。
- **依赖**：G1、G2、G3、云厂商转写 API + 外呼系统开放 API/回调。
- **验收**：租户配置外呼系统回调或 API Key 后，通话记录+录音自动回流 → 自动出复盘 → 一键落跟进。

**远期：AI 机器人外呼（对接供应商，不自建）**
- **做什么**：AI 机器人主动外呼，对接外呼供应商的机器人服务（百应/探迹/阿里云外呼等），我们只做**集成层**：名单/话术/结果回传。
- **不自建 FunASR/CosyVoice GPU 语音引擎**（成本高、门槛高）；语音听/说全走供应商接口。
- **合规**：内置 AI 语音标识声明、呼叫时段限制、拒接名单（Do-Not-Call）、反诈拦截开关。
- **依赖**：G1、G2、G3、功能 11（声音，可选）；走增值包。

### 功能 10 — 线索爬取 + 竞品/行业洞察
- **做什么**：按行业/关键词抓公开线索 + 竞品动态/行业趋势，进线索池。
- **来源**：scrapling、browser-use / jev-ultrafast（无脚本浏览器）、MiroFish、WeMM。
- **依赖**：G1、G2、G3；合规边界需评估。
- **验收**：输入关键词产出线索清单（含来源），可导入线索池。

### 功能 11 — 声音克隆（能力组件）
- **做什么**：克隆指定音色，供功能 7（数字人）、功能 9（外呼）复用。
- **来源**：VoxCPM、WeClone；CosyVoice（自带音色克隆，可选）。
- **依赖**：G1、G2、G3；走增值包；需合规授权声明。
- **验收**：上传样本产出可用的克隆音色。

### 功能 12 — AI 问数 BI（大白话查数，Text-to-SQL）
- **做什么**：销售/财务看板「大白话问数」——自然语言 → SQL 直连 MySQL 出图表，省去手写报表。
- **来源**：vanna（MIT，Text-to-SQL 直连 MySQL）。
- **依赖**：G1、G2、G3；财务/应收模块已建，正好接回款/合同数据。
- **复用**：数据大屏（经营大屏）的 AI 数字人问答，底层复用此 Text-to-SQL 能力。
- **验收**：输入「上月各客户回款金额 Top10」，返回结果 + 图表 + 生成的 SQL。

## 五、嵌入型与平台型能力（本次新增）

### 功能 13 — 客户画像分析（嵌入型）
- **做什么**：销售打开线索/客户/商机详情页，一眼看到 360° 画像（谁、值不值得跟、卡在哪、下一步）。**不独立成模块，长在详情页里。**
- **数据源**：`ai_analysis_result` 表（各 AI 分析结果沉淀）+ 现有客户/跟进/商机/订单数据，**只读聚合，不增删改**。
- **底座**：G1 四步链路；上级看下级行级权限，只读。
- **计费**：查看型，**订阅内权限限不限次**（只挂 G3，不挂 G2 计量）。
- **版本归属**：专业版+。
- **验收**：打开客户详情页，画像卡片展示 360° 信息 + 下一步建议。

### 功能 14 — 数据大屏 = 经营大屏（平台型）
- **做什么**：老板视角企业客户数据驾驶舱，中间 AI 数字人 + 左右数据维度。
- **底层**：数字人问答复用功能 12 问数 BI 的 Text-to-SQL；数据吃前 12 个功能的沉淀数据。
- **数字人**：**2D 真人感数字人**（真人录制 + AI 口型驱动，SadTalker/MuseTalk 等），3D 单列为可选增值（成本高、有恐怖谷风险，不做默认项）。
- **计费**：查看型，**免费（全租户可见）**，不限次。
- **与 dashboard 关系**：原 dashboard「经营大屏建设中」占位页即此能力，DataEase 已隐藏。
- **验收**：老板登录看全局驾驶舱，AI 数字人可语音/文字问答查数。

## 六、数据底座与导航定位

### 6.1 ai_analysis_result 表（客户画像的数据底座）
- 唯一新增表：`ai_analysis_result`（`tenant_id` + 业务对象 id[客户/线索/商机] + 分析类型 + 结论 JSON + 时间）。
- 所有 AI 功能的分析结果落这一张；客户画像读它；数据大屏聚合它。
- **必须按 `tenant_id` 隔离**（多租户数据隔离是命门）。

### 6.2 导航定位：三类分流（AI 能力跟着业务走，顶层只留大屏）

| 类型 | 去向 | 能力 |
|---|---|---|
| 嵌入型 | 详情页/列表，**不占菜单** | 客户画像分析（功能 13）、会话军师未来可嵌入客户详情 |
| 独立型 | 「AI 中心」一级菜单（智能工作台升级） | 功能 1~12（话术库/获客内容/知识库/方案PPT/AI员工/短视频/私信画像/外呼/爬取/声音/问数BI） |
| 平台型 | 独立一级入口 | 数据大屏 = 经营大屏（功能 14） |

## 七、执行顺序（推荐）

1. **P0 地基（G1→G2→G3）**：先解耦模型 + 建额度 + 功能开关，这一步做完，后面所有 AI 功能才能「上线即收费、可计量、可关停」。（注：G1-G3 已基本完成，会话军师已建在其上。）
2. **一期（功能 1→2→3）**：功能 1（会话军师）已上线，功能 2（话术库）给它供话术，功能 3（获客内容）紧随；都是文本类低 token 成本，打包进订阅价。
3. **二期（功能 4→…→12 + 13）**：先 4（知识库 RAG 基座，低本高复用），再按「中成本→高成本」做方案/PPT(5)、AI 员工(6)、线索(10)、短视频(7)、私信(8)、外呼(9)、声音(11)，高成本生成类走增值包；12（问数 BI）成本低可提前；13（客户画像）依赖 `ai_analysis_result` 表地基，可随二期排。
4. **最后（功能 14 数据大屏）**：吃前 12 个功能的沉淀数据，接 2D 数字人。
5. 每个功能开工前，单独展开一份该功能的详细 PRD + 数据模型 + 接口清单，再动手。

## 八、合规与设计约束

1. **第三方模型数据合规（PIPL / 数据出境）**：客户数据喂豆包/千问前脱敏（手机号/身份证），模型厂商数据条款 + 租户授权声明。
2. **多租户数据隔离**：话术库/知识库/画像/`ai_analysis_result` 全部按 `tenant_id` 隔离（RAG 向量库按租户分集合）。
3. **AI 结果免责 + 人工确认**：画像/话术/方案/合同风险提示均为「AI 生成仅供参考」，关键动作人工确认。
4. **新增能力的版本归属 + 收费**：客户画像 = 专业版+；数据大屏 = 免费全租户；查看型不限次，生成型计量（见 §1.2）。
5. **数字人分档**：2D 真人感先行，3D 单列可选增值，避免被 3D 成本卡住大屏上线。
6. **用量透明**：生成类 AI token 成本要可查（租户「次数」看板 + admin「成本」看板），避免租户意外超量。

## 九、来源仓库已下载说明

已下载参考仓库：ragflow/MaxKB（RAG）、PaddleOCR（OCR，会话军师已弃用改豆包多模态）、FunASR/CosyVoice（语音）、vanna（问数）、kev（打分）、ax/n8n/Octop（AI 员工编排）、univer（Office 渲染/编辑运行时，非 AI 生成）、jev-ultrafast（无脚本浏览器）、MoneyPrinterTurbo（短视频成片）、ZJU-REAL/Easel（自媒体一条龙）、qdrant（向量库）、langgraph（Agent 编排运行时）、markitdown（文档转 Markdown）。

**ZJU-REAL/Easel 单独说明**（Apache-2.0，Python + OpenClaw，113 个 skill，759M）：它是「获客 + 传播」线的**整合参考底座**，五段式覆盖 发现 → 策划 → 创作 → 发布 → 复盘。对应功能 3（获客内容）、功能 7（短视频）、功能 8（私信获客）三处，可复用其 skill prompt + 脚本思路。两个边界：① 它是独立 Python 系统（含 Web UI），只能「抄思路 + prompt + 脚本」，不能整搬进 Java/Vue CRM；② 它的「一键自动发布」有封号风险，与本清单「内容生成 + 手动下载发布」口径一致——只参考创作侧，不接自动发布侧。

**未纳入本清单的下载项**（非 AI 功能，留作产品/安全参考）：四类借鉴系统（skyeye/metasfresh/t3rik-erp/wimoor/OmniTradeERP/mall/litemall/newbee-mall/lobe-chat/dify/open-webui）是 ERP/电商/AI 超市的产品与架构参考；security-audit-skill（供应链安全）、openbao（密钥托管）属安全基建，均不与 AI 功能一一对应。

## 十、去重与模块关系

- **已合并**：原「功能 1 客户军师」与「功能 4 企微会话分析」分析维度几乎 100% 重叠（意向/信号/异议/竞品/流失风险），仅是输入通道不同 → 合并为「功能 1 销售会话军师」（粘贴 / 截图 / 企微存档多通道），避免重复开发。
- **底座复用（非重复）**：功能 2（话术库）与功能 4（知识库）共用同一个 RAG 底座（ragflow），只是知识域不同（话术域 vs 企业文档域）。
- **组件复用（非重复）**：功能 11（声音克隆）是能力组件，被功能 7（数字人）、功能 9（外呼）复用；功能 2（话术库）被功能 1（候选话术）复用；功能 4（知识库）被功能 5/6 复用；功能 12（问数 BI）被功能 14（数据大屏数字人问答）复用。
- **编排层（非并列功能）**：功能 6（AI 员工）是把 1~12 的原子能力包成「岗位 Agent」的编排/平台层，不是与它们平级的单个功能。
- **边界提醒**：功能 3（文本/图文内容）与功能 7（视频）共享「选题/策划」环节，但生成管线与成本差异大，分开保留；功能 8（私信画像）与功能 10（线索爬取）同属「获客线索采集」但来源/实现不同，分开保留；功能 13（客户画像）是 CRM 内 360° 聚合（只读），与功能 8（外部私信画像）是两个不同维度，不重复。
