## 一、总览

**总共：3 项地基 + 12 个 AI 功能 + 2 项新增能力（客户画像 / 数据大屏）。**

开发优先级 = 序号从前往后做。地基（G1→G3）是所有 AI 功能收费/运行的前提，必须先做；功能（1→12）按「成本低 → 价值高 → 依赖少」排序。

### 1.2 计费分层（查看型不限次，生成型计量）

| 类型 | 收费方式 | 功能 | 底层 |

| **查看型**（展示已分析好的结果，成本低/可缓存） | **订阅内权限限，不限次** | 客户画像、数据大屏、问数BI 预置报表 | 只挂 G3（feature_code 权限开关），**不挂 G2 额度计量** |

## 二、地基（P0，先做）

### G1 — 模型可配置适配层（分场景路由）
- **做什么**：抽象 `LlmProvider` 接口，实现千问（DashScope）/ DeepSeek / 豆包（火山引擎）/ MaxKB；一张「场景路由」配置把 `feature_code → model_code`，**不同 AI 功能用不同模型**（军师→千问、获客文案→豆包、生成类→专门生成模型）。
- **统一出口**：每次调用把 `usage`（input/output token 分开）吐给计量层，供 G2 记账。
- **依赖**：无（替换现有写死的 `AgentBaseService` 里的 `config.getMkAddress()`）。
- **验收**：配置里切换模型后，AI 对话无需改代码即走新模型；`usage` 字段能取到 input/output token。

### G2 — AI 额度框架（计量/配额/加购/熔断/双看板）
- **做什么**：PRD §9 全部——计量（按 token 折「次数」）、月配额次月 1 日重置、加购包、软超(100–110% 限速提示)/硬超(>110% 停用)、单租户限流 + 单日成本熔断、租户端「次数」看板 + admin「成本」看板。
- **依赖**：G1（拿 usage）、G3（按功能区分计量）。
- **验收**：某租户额度用尽后 AI 功能按规则停用/提示；admin 能按租户/天看真实 token 成本。

### G3 — AI 功能挂 feature_code（版本/全局开关）
- **做什么**：把各 AI 功能注册 `feature_code`，挂到 `sys_feature` + `sys_edition_feature`，支持「版本归属」+「全局开关」两个维度（表已建，只接线）。查看型功能（画像/大屏）只挂这一层，不走额度计量。
- **依赖**：无。
- **验收**：admin 勾选某版本含某 AI 功能后，该版本租户可见该功能入口；全局禁用后所有租户入口隐藏。

## 三、第一期 AI 功能（签单 + 获客，低 token 成本，打包订阅价）

### 功能 1 — AI 销售会话军师（多通道：粘贴 / 截图 / 企微存档）
- **做什么**：销售把与客户的聊天通过「粘贴文本 / 截图 / 企微会话存档（后续）」交给 AI → 输出 意向评分、成交信号、异议点、情绪/满意度、竞品提及、流失风险 → 候选话术（从话术库检索+改写）→ **一键转跟进**。
- **复用**：现有 Agent 平台（对话/流式/确认）+ G1 模型层；截图走豆包多模态直接读图（不 OCR）。
- **来源**：豆包 vision 多模态（读图）；企微「会话存档 API」等上线后再接（受企业可信 IP 60020 限制）。
- **依赖**：G1、G2、G3、功能 2（话术库，可选）。
- **验收**：粘贴/截图一段对话，30s 内出结构化分析 + 话术，可一键落跟进记录。
- **进度**：`[x]` 已上线（`/agent/advisor/analyze`，featureCode=`ai_advisor`）。

### 功能 2 — 销售话术库（RAG 检索）
- **做什么**：租户沉淀自己的销售话术/常见异议应答，AI 按客户情况检索并改写推荐话术；也是功能 1「候选话术」的数据源。
- **来源**：ragflow / MaxKB（RAG 检索底座），qdrant（向量库）。
- **依赖**：G1、G2、G3。
- **验收**：输入客户场景，返回 3 条贴合的话术 + 出处。
- **进度**：`[x]` 已上线（话术维护 + Excel 导入 + AI 检索改写推荐，featureCode=`ai_sales_rag`）。

### 功能 3 — AI 获客内容生成（选题/文案/图文）
- **做什么**：输入行业/产品，AI 生成抖音/小红书/朋友圈的选题、爆款文案、配图文案。
- **复用**：`marketingskills` 等已下载 skill 的 prompt 模板；ZJU-REAL/Easel（自媒体选题/创作/发布一条龙）；应用编排参考 dify / lobe-chat。
- **依赖**：G1、G2、G3。
- **验收**：一键生成 5 条选题 + 对应文案，可复制/导出。
- **进度**：`[x]` 已上线（选题/文案/配图文案，featureCode=`ai_acquire`）。

## 四、第二期 AI 功能（生成类 / 企业版，高成本走增值包）

### 功能 4 — 企业知识库（RAG + 文档解析）
- **做什么**：租户上传产品文档/合同/手册，AI 解析建库，问答/检索。是后续多个功能的 RAG 基座。
- **来源**：ragflow（首选，Apache-2.0）/ MaxKB（GPL）/ 腾讯 WeKnora（GPL）；文档解析 **anydoc（扫描件 OCR 重解析）+ markitdown（电子版 Office/PDF 转 Markdown，微软 MIT，轻快）** 互补。
- **依赖**：G1、G2、G3。
- **验收**：上传文档后可自然语言问答，答案带出处。
- **进度**：`[x]` 已上线（文档解析 + 检索问答，出处片段长度可配 ai.kb.snippet_max，featureCode=`ai_kb`）。

### 功能 5 — AI 方案/PPT 生成
- **做什么**：输入客户背景，AI 生成解决方案大纲 + PPT 初稿。
- **来源**：dashi-ppt、anydoc；Office 运行时参考 univer。
- **依赖**：G1、G2、G3、功能 4（知识库，可选）。
- **验收**：输入需求，产出可下载的方案文档/PPT。
- **进度**：`[x]` 已上线（两步式 `/agent/ppt/outline/stream` → `/agent/ppt/slides/stream`，featureCode=`ai_ppt`，前端 pptxgenjs 出 .pptx；当前为「模板 + 品牌配色」纯文本版式，**只够上线用，后续必升级**）。
- **后期迭代计划**：
  - **中期·一眼漂亮（自研，不引库）**：把「标题+要点」单一版式升级为**页面角色版式**——后端逐页结构化输出加 `role` 字段（封面/目录/指标/趋势/对比/流程/风险/结尾等 20 类），前端按角色选版式出图，替代现在的纯文本版式；导出继续用 pptxgenjs 客户端出 .pptx。对标 dashi-ppt-skill 的「版式 + 文案字段」思路，但**不引其代码/主题/模板**（该仓 AGPL-3.0，多租户 SaaS 不可用）。
  - **文生图配图（锦上添花）**：独立工程（文生图出图 → 存库 → pptxgenjs 嵌图），不做主线；换 LLM 模型解决不了，属额外工作量。

### 功能 6 — AI 员工（144 员工，编排层）
- **做什么**：把 144 个 AI 员工 skill 落成租户可配置的 Agent（岗位分工、自动跑任务），在现有 Agent 平台上发布。
- **来源**：agency Agents、metagpt、144 个 AI 员工 repo；编排运行时参考 google/ax、n8n（工作流）；私有助手参考 TencentCloud/Octop；企业数字员工平台参考 LinkWork（Apache-2.0，配额/审计/K8s）与 StaffDeck（⚠️AGPL，仅抄思路）。
- **依赖**：G1、G2、G3、功能 4（知识库赋能）。
- **验收**：租户可创建/配置一个「岗位 Agent」，跑通一个端到端任务。
- **进度**：`[x]` 第一版已落地：角色目录 264 岗位浏览/搜索 + 岗位 Agent 增删改查（含自定义提示词、挂知识库开关）+ 流式对话（角色提示词 + 自定义提示词 + 知识库检索上下文注入）+ 虚拟会议室编排（董事长提问 → 各岗位依次发言 → 可选「深入讨论」轮 → 结构化会议纪要落库回看）。
- **后期迭代计划**：
  - **自动跑任务（大工程）**：让岗位 Agent 调用 CRM 原子能力（查客户/查订单/生成内容/写跟进）自动拆解并执行多步任务，参考 google/ax、n8n（工作流）、TencentCloud/Octop、LinkWork；需 function calling + 工具注册 + 任务状态机 + 前端进度可视化，属下一版本，不纳入第一版收尾。

### 功能 7 — 短视频/数字人/爆款复刻
- **做什么**：上传素材 → 生成口播视频/数字人视频/爆款复刻，用户手动下载发布（不做自动发布，防封号）。
- **来源**：MoneyPrinterTurbo（纯 AI 文本成片，首选）/ ZJU-REAL/Easel（图文转视频 slideshow-video + AI 视频生成 ai-video-gen）/ LongCat、avatar-forge、hypit、OpenMontage、FFmpeg。
- **依赖**：G1、G2、G3；走增值包加购。
- **验收**：上传素材产出可下载视频 + 各平台配套文案。
- **进度**：`[x]` 口播短视频第一版已上线（LLM 分镜 → Seedream 配图 → TTS 配音 → FFmpeg 合成 → 附件 + 抖音/小红书/朋友圈配套文案，featureCode=`ai_video`）。
- **进度（漫剧）**：`[x]` AI 漫剧 v1 已封存（仅平台 admin 可见，不对外开放；脚本工作流：主题 → 大纲/分集剧本 → 资产库抽取角色/场景 → 逐镜 Seedream 生图 → TTS 口播 → 可选 Seedance 图生视频 → FFmpeg 合成 1080×1920 成片 + 下载，featureCode=`ai_drama`）。
- **升级**：升级为一级「**AI 创作中心**」（短视频模板库 / 漫剧 / 工具中心 / 资产库 / 定价钱包），详见 [AI创作中心-融合方案.md](./AI创作中心-融合方案.md)。
- **爆款复刻（排期在漫剧之后，自研）**：对标开源 hypit（丢参考视频 → 产出 100 变体、~$1/条），但 hypit 是「改版 Apache 2.0 + 附加条款」，**明确禁止多租户 SaaS / 捆绑进卖给第三方的产品**，只能抄思路自研：① 视频文本化描述（SVML 类，文字锚定时间轴）；② WhisperX 词级对齐做卡拉OK字幕；③ 无头 Chromium/Canvas 渲染字幕+动效。复用现有 printfilm 复刻 + 27 模板 + 短视频管线（LLM 分镜→Seedream 配图→TTS→FFmpeg 合成）。

### 功能 8 — 私信获客画像（抖音/快手/小红书，Beta）
- **做什么**：租户绑定自己账号（登录态迁移：Cookie 为主、扫码为备）→ 读私信 → AI 画像（性别/年龄/品类/话术）→ 进 CRM 客户池。
- **来源**：16.test + scrapling（Python 微服务）。
- **硬约束**：只拿租户自己账号私信；封号风险租户自担 + 小号先试 + 限频 + 免责声明。
- **依赖**：G1、G2、G3、独立 Python 微服务（Playwright，每租户几百 MB 内存）。
- **验收**：Beta 环境跑通「绑定→读私信→画像→进客户池」。
- **PRD**：[私信获客画像-PRD.md](./私信获客画像-PRD.md)（已出第一版，登录=登录态迁移、Python 只做采集、画像走 CRM G1 层）。
- **进度**：`[x]` Beta 已落地（抖音 Cookie 绑定→采集→AI 画像→导入线索池→转客户带入画像快照→客户详情「私信画像」tab 展示；快手/小红书标注待开发）。

### 功能 9 — 智能通话复盘（第一版） + AI 机器人外呼（远期）

**第一版：智能通话复盘（配置化对接外呼系统，不自建呼叫）**
- **做什么**：销售用**已经在用的外呼系统**打电话（百应/探迹/容联/阿里云外呼，或长尾小厂），通话数据（记录+录音）回流 CRM → 语音转文字 → AI 分析（意向/异议/话术/复盘）→ 落跟进。本质是**会话军师的「语音通道」**。第一版最轻：不碰呼叫、不碰线路、不碰实时语音。
- **三层接入架构**：
  1. **通用回调接入（兜底长尾，零开发）**：CRM 提供统一回调地址 + 密钥 + 「字段映射」配置页；任何外呼供应商把通话结果（通话时间/主叫/被叫/时长/录音 URL/转写文本）POST 到回调地址，租户在配置页把供应商字段映射到 CRM 标准字段即接入。**覆盖所有中小便宜厂商，不用一家家开发适配器**。
  2. **官方适配器（4 家预置，开箱即用）**：容联云、百应、探迹、阿里云外呼——主动拉取 + 预置字段映射，租户只填 API Key/授权。**分阶段做**（先 1 家跑通样板，再复制 3 家）。
  3. **（远期）自建点击呼叫**：闭环呼叫，另议。
- **语音转文字**：云厂商录音转写 API（按量计费 2.5 元/时标准 / 1.56 极速 / 0.6 闲时，转嫁租户）。
- **AI 分析**：复用会话军师 LLM 逻辑。
- **关键前提**：依赖外呼系统的 API/回调开放程度；「配置化」省实施对接人工、不省适配开发——所以大牌走官方适配器、长尾走通用回调。
- **不做**：不做机器人外呼、不碰实时语音引擎、不自建 GPU、不自建点击呼叫（第一版），零风控、零 GPU 成本。
- **依赖**：G1、G2、G3、云厂商转写 API + 外呼系统开放 API/回调。
- **验收**：租户配置外呼系统回调或 API Key 后，通话记录+录音自动回流 → 自动出复盘 → 一键落跟进。
- **进度**：`[x]` 已上线第一版（通用回调 + 录音转写 + AI 复盘 + 一键转跟进，featureCode=`ai_call_review`；机器人外呼为远期，不自建）。

**远期：AI 机器人外呼（对接供应商，不自建）**
- **做什么**：AI 机器人主动外呼，对接外呼供应商的机器人服务（百应/探迹/阿里云外呼等），我们只做**集成层**：名单/话术/结果回传。
- **不自建 FunASR/CosyVoice GPU 语音引擎**（成本高、门槛高）；语音听/说全走供应商接口。
- **合规**：内置 AI 语音标识声明、呼叫时段限制、拒接名单（Do-Not-Call）、反诈拦截开关。
- **依赖**：G1、G2、G3、功能 11（声音，可选）；走增值包。

### 功能 10 — 线索爬取 + 竞品/行业洞察

## 八、合规与设计约束

1. **第三方模型数据合规（PIPL / 数据出境）**：客户数据喂豆包/千问前脱敏（手机号/身份证），模型厂商数据条款 + 租户授权声明。

6. **用量透明**：生成类 AI token 成本要可查（租户「次数」看板 + admin「成本」看板），避免租户意外超量。
