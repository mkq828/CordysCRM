# AI 创作中心 — 融合方案（借鉴 printfilm）

> 定位：把现有「功能 7 · 短视频生成」升级为一级入口「**AI 创作中心**」，融合 printfilm 的产品形态与商业化。
> 参考：[AI模块-落地清单.md](./AI模块-落地清单.md)（3 地基 + 12 功能 + 2 能力）；printfilm（MIT，已本地部署 `/tmp/printfilm` mock 版供对照 UI：web=8080 / admin=18081 / api=18000）。
> 结论一句话：**不搬 printfilm 整套（它自带账号/计费/admin），只搬「产品形态 + 商业化 + UI」这 5 块，映射到我们已有的地基与功能 7 上。**

---

## 一、最终效果（验收口径）

一个丰富、可选、可计费的 **AI 内容创作工作台**，一级菜单「AI 创作中心」，下面 5 个 tab：

| tab | 最终效果 |
|---|---|
| **短视频** | 模板库（20+ 模板/爆款复刻）、多风格、BGM/转场/字幕样式可选；成片不假、不「换灯片」，文案真正用上 |
| **漫剧** | 创业老板把人生经历/创业史拍成 AI 漫剧，公司/产品宣传漫剧；角色跨镜头一致 |
| **工具** | 8 个低成本小工具（抠图/文生图/放大/扩图/文案改写/爆款标题/口播脚本/去水印转格式） |
| **资产** | 租户可自建 + 系统预置：音色库、无版权 BGM 库、字体库、背景空镜库、角色/场景库、字幕样式/转场 |
| **定价** | 余额钱包 + 分档单项额度包，额度用完可单独充值 |

工作台 UI 参考 printfilm 漫剧布局：**左资产栏 / 中画布编辑器 / 右任务列表**。

## 二、融合原则

1. **不搬它的账号/计费/admin** —— 我们已有租户体系、订阅套餐、`feature_code` 版本开关、G2 额度框架，比它的更贴合 CRM。
2. **搬它的产品形态** —— 把散落的创作能力收进一个统一「AI 创作中心」，不再单页孤立。
3. **商业化和 UI 借鉴它** —— 余额钱包 + 分档额度包 + 租户自建资产库，这是它「商业化、可选性强」的来源。

## 四、计费：余额钱包 + 分档额度包

- **钱包**：每租户一个 AI 余额（分），所有生成类功能从这里扣费；订阅内赠送额度照旧。
- **分档额度包**（按功能卖，不是只卖一个总包）：短视频条数包、漫剧集数包、文生图张数包、声音克隆次数包、工具次数包。
- **充值**：租户额度用尽 → 引导「单独充值单项功能额度包」（管理后台发单/线下确认，第一版不做在线支付，走「申请 → 客服确认 → 充值到账」）。
- **熔断不变**：软超（100–110% 限速提示）/硬超（>110% 停用）沿用 G2 规则，只是额度来源从「月配额」扩展为「月配额 + 已购额度包」。

## 五、分阶段任务拆解

### Phase 0 · 计费地基（余额钱包 + 分档额度包）
- [ ] 建 `ai_wallet`（租户余额）+ `ai_quota_pack`（额度包商品）+ `ai_quota_pack_order`（购买/充值记录）三张表，按 `tenant_id` 隔离。
- [ ] 后端：额度扣减统一走「月配额 → 已购包」两层，出余额/额度看板接口。
- [ ] 前端：租户「我的额度」页（各功能剩余次数 + 可买额度包列表 + 申请充值）；admin「额度包管理 + 审核到账」页。

### Phase 1 · 可选性快赢（模板库 + 工具中心）
- [ ] 功能 7 升级：视频模板库（多风格模板 + 爆款复刻）、BGM 库、转场/字幕样式可选（复用现有 FFmpeg/ASS 合成，把硬编码改配置化）。

### Phase 2 · 漫剧轻量版 + 资产库
- [ ] 新增「创作资产库」：音色/BGM/字体/背景空镜/角色/场景，租户可自建 + 系统预置（BGM 优先 CC0/无版权）。

- [x] **Seedance 图生视频（核心价值）**：逐镜把 Seedream 首帧 → 图生视频（画面真动、出片自带口播），接角色一致性资产；这是漫剧与「网上简单轮播」拉开差距的门槛。✅ 已落地：逐镜 Seedance 图生视频（3 并发）+ 合成优先用视频片段、无视频回退静图；角色一致性 subject reference（多参考图锁定）仍单列里程碑。
- [ ] 声音克隆（功能 11）打通，供漫剧/短视频配音复用。
- [ ] 额度包全链路在线化打磨（充值到账实时化、扣费透明化）。
- 验收：漫剧画面真实动起来，角色一致，全链路可计费、可看板。

## 六、合规与约束

1. **BGM 版权**：资产库 BGM 优先 CC0/无版权源，不引入侵权风险。
2. **角色一致性**：漫剧靠「视觉锚点/资产库」保证主角跨镜头不穿帮，这是漫剧护城河。
3. **Seedance 真视频是核心门槛**：图生视频（画面真动、角色一致）是漫剧的核心价值，必须做；轻量版（漫画分镜+口播+Ken Burns）只作首帧预览/低成本兜底档，不是最终形态。成本靠「分档额度包」转嫁租户。
4. **多租户隔离**：资产库/钱包/额度包全部按 `tenant_id` 隔离。
5. **下载发布**：沿用「生成 → 手动下载发布」，不做一键自动发布（防封号）。
6. **第三方模型合规**：喂模型的客户数据先脱敏，沿用现有口径。

---

## 七、去重与模块关系

- 「AI 创作中心」是功能 7（短视频）的**形态升级**，不是新并列功能；漫剧、工具、资产、定价钱包是它的四个子模块。
- 资产库被短视频（BGM/字体/背景）与漫剧（角色/场景）共用，是**跨模块底座**。
- 声音克隆（功能 11）是能力组件，被漫剧/短视频配音复用。
- 定价钱包（Phase 0）是对 G2 额度框架的**扩展**（月配额 → 月配额 + 已购包），不替换 G2 计量/熔断。
